# JARVIS Core UI

The home screen now uses an animated JARVIS nucleus instead of a static microphone ring.

States:
- Listening — cyan glow and microphone icon
- Thinking — violet glow and thinking icon
- Working — gold glow and gear icon
- Completed — green glow and check icon
- Error — red glow and warning icon
- Standby — gold idle state

The nucleus has animated orbit particles, state-specific glow, subtle system sound cues and haptic feedback. The home screen also includes quick command chips for AI, Tools, Vision and Devices.
