# JARVIS — المساعد الذكي الشخصي

تطبيق مساعد شخصي بنسختين منفصلتين: **المستخدم** (واجهة JARVIS الداكنة بالذهبي) و**المطور** (لوحة تحكم كاملة).

## التشغيل

```bash
flutter pub get
flutter run
```

## تسجيل دخول نسخة المطورين

في `PermissionService.login` مرّر الرمز التجريبي: `JARVIS-DEV-2026`

## بنية المشروع

| المسار | الوصف |
|---|---|
| `lib/core/permissions` | فصل النسختين + RBAC |
| `lib/data/services` | الأجهزة (MQTT)، التذكيرات، الصوت، الرؤية |
| `lib/features/user` | نسخة المستخدم: الرئيسية، الكاميرا، الأجهزة، التذكيرات |
| `lib/features/developer` | نسخة المطور: الأذونات، OTA، السجلات |

## قبل الإنتاج

1. استبدل `PermissionService.login` بمصادقة حقيقية (Firebase Auth / JWT)
2. فعّل MQTT: `DeviceService.connectMqtt(host: ...)`
3. أضف مفاتيح API الخاصة بنماذج الرؤية إن رغبت بنماذج سحابية
4. اختبر الإشعارات على جهاز حقيقي (الإشعارات لا تعمل على المحاكي)
