# JARVIS Premium UI — v6

The home experience now includes a cinematic HUD layer built without additional packages:

- Reactive ambient grid, orbit lines and particles tied to the JARVIS nucleus state.
- Live system activity strip with AI / backend / MQTT / GPS indicators.
- Animated screen transitions between Home, AI, Design and Profile.
- Frosted-glass bottom navigation with a subtle gold ambient glow.
- Premium gradient cards with restrained shadows.
- Existing JARVIS nucleus states remain the source of truth for the visual state machine.

Design principle: the UI should feel alive while remaining readable, battery-conscious and functional on a mid-range Android phone.
